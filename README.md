# 海豹冲冲冲 (Seal Rush)

3D 无尽雪坡与冰海滑行网页小游戏（单文件零构建 Three.js + Web Audio）。

- **在线试玩**：https://loopdew.github.io/seal-rush/

## 玩法与特性
- **雪坡 & 大冰海板块交替**：开局雪坡后，560m 冰海板块（`entry` → 6 段深海 → `exit`）与 560m 雪坡等量交替推进；配合极地晴日、冰川峡谷、极光夜、玫瑰晨曦四种动态天色循环，支持冲刺与无障碍禅意模式。
- **默认入水潜泳 & 破水跃出**：滑入冰海后自动潜入水下畅游，可随时蓄力破水跃出水面；水下按深潜贴近海底躲避冰崖悬冰，水下遇冰礁或浮冰可破水飞跃，空中可触发肚皮砸地 / 鱼雷入水。
- **三层水道与交互**：高中低三层冰晶水流环与小鱼阵、首页轻点/拖曳光标与海豹逗趣互动（触发转体顶金球彩蛋），支持 4 款毛线帽与围巾配色切换。
- **版本备份**：`backups/` 目录保留单文件历史版本（`index.fable5.2.html` 原版、`index.v2-lagoon.html`）。

## 操作说明
- **桌面端**：`A` / `D` 或 `←` / `→` 转向；`空格` / `W` / `↑` 雪地起跳或水中破水跃出；空中再按或 `S` / `↓` 肚皮砸地 / 鱼雷入水；水中 `S` / `↓` 深海下潜；`M` 静音；`P` / `Esc` 暂停。
- **移动端**：按住左右拖动转向，轻点起跳或破水跃出，向下滑动触发肚皮砸地或深海下潜。
