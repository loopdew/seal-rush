# 海豹冲冲冲 (Seal Rush)

3D 无尽雪坡与冰海滑行网页小游戏（单文件零构建 Three.js + Web Audio）。

- **在线试玩**：https://loopdew.github.io/seal-rush/

## 玩法与特性
- **雪坡滑行 & 极光天色**：极地晴日、冰川峡谷、极光夜、玫瑰晨曦四种动态天色循环，支持冲刺模式与无障碍禅意模式。
- **冰海水道 & 水下潜泳**：滑入冰海后可水面畅游（人字形开尔文尾波），或下潜水底躲避浮冰、穿过冰晶水流环并破水空翻。
- **首页互动与装扮**：轻点或拖动鼠标可与海豹互动逗趣、触发转体顶金球彩蛋，并支持 4 款毛线帽与围巾配色切换。

## 操作说明
- **桌面端**：`A` / `D` 或 `←` / `→` 转向；`空格` / `W` / `↑` 跳跃或破水；空中再按或 `S` / `↓` 肚皮砸地 / 水下潜泳；`M` 静音；`P` / `Esc` 暂停。
- **移动端**：按住左右拖动转向，轻点起跳或破水跃出，向下滑动肚皮砸地或潜泳。
